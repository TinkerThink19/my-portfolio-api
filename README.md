# My Portfolio API

A simple public Express API for a React portfolio website.

## Features

- Public access without authentication
- CORS enabled for frontend access
- Endpoints for profile, skills, projects, and health checks

## Installation

```bash
npm install
```

## Run

```bash
npm start
```

For development:

```bash
npm run dev
```

## Endpoints

- `GET /api/health`
- `GET /api/profile`
- `GET /api/stats`
- `GET /api/skills`
- `GET /api/projects`

## Example

```bash
curl http://localhost:5000/api/health
```
